# Modulation & Demodulation Simulator

A MATLAB/Octave project developed for the IT103 Communications Course.

## Overview

This project demonstrates the implementation of both analog and digital modulation techniques:

- AM (Amplitude Modulation)
- FM (Frequency Modulation)
- ASK (Amplitude Shift Keying)
- FSK (Frequency Shift Keying)

The simulator performs:

- Signal Generation
- Modulation
- Demodulation
- Signal Visualization
- Comparison between modulation techniques

## Project Structure

---

## AM Modulation

AM changes the amplitude of the carrier signal according to the message signal.

Advantages:
- Simple implementation
- Low bandwidth requirement

Disadvantages:
- Highly affected by noise

---

## FM Modulation

FM changes the frequency of the carrier signal according to the message signal.

Advantages:
- Better noise resistance
- Higher signal quality

Disadvantages:
- Larger bandwidth requirement
- Higher complexity

---

## ASK Modulation

ASK transmits digital data by varying the carrier amplitude.

Advantages:
- Simple implementation
- Low bandwidth

Disadvantages:
- Sensitive to noise

---

## FSK Modulation

FSK transmits digital data by varying the carrier frequency.

Advantages:
- Better noise immunity
- Lower bit error rate

Disadvantages:
- Higher bandwidth requirement

---
